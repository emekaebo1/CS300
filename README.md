  The projects in this course focused on developing an advising assistance program for ABCU's Computer Science department. The goal was to organize course information, display courses in alphanumeric order, and allow academic advisors to look up courses and their prerequisites. I approached the problem by analyzing different data structures and their runtime and memory requirements before implementing the program in C++. I used a vector to store Course objects and implemented functions to load course data from a CSV file, sort the course list, and display course information. This project helped me understand why choosing the right data structure matters because it affects how efficiently a program stores, searches, and organizes information. One roadblock I encountered was getting the program to locate the CSV file in Visual Studio. I resolved this by checking the file's location, the project's working directory, and the filename. This experience taught me to troubleshoot problems systematically rather than immediately assuming the code was incorrect.
  
  Working on these projects expanded my approach to software design by encouraging me to consider requirements, performance, and data organization before writing code. I learned that selecting an appropriate algorithm and data structure can make a program more efficient and easier to maintain. I also improved my understanding of how to write readable and adaptable code by using descriptive variable names, comments, and separate functions for different tasks. Adding input validation and error messages helped make the program more reliable when users entered invalid information or requested courses that did not exist. Overall, this course strengthened my ability to evaluate different approaches to solving programming problems and reinforced the importance of writing code that is organized, maintainable, and adaptable to future changes.
